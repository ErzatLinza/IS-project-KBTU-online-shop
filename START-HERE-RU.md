# Как запустить сайт с каталогом из PostgreSQL

1. Скопируй `.env.example` в новый файл `.env` в этой же папке.
2. В `.env` укажи имя пользователя PostgreSQL и пароль, которые используются для подключения к серверу в pgAdmin. База уже называется `kbtu_shop`.
3. Открой Terminal и перейди в папку проекта:

   ```sh
   cd ~/Desktop/OnlineShop
   ```

4. Установи зависимости и запусти сайт:

   ```sh
   npm install
   npm start
   ```

5. Открой `http://localhost:3000` в браузере. Над каталогом должна появиться надпись о подключении и количестве загруженных товаров.

На первом этапе сайт только читает каталог из PostgreSQL через `GET /api/products`. Заказы и изменения остатков пока сохраняются в браузере; запись заказов в базу подключается отдельным следующим шагом.
